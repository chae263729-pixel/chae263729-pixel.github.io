Webサイト制作指示書

1. 企画・コンセプト

選択テーマ: 未経験からプロを目指す実践型WebプログラミングスクールのLP（ランディングページ）

参考イメージ: 近未来的でビビッド（ダークモード基調、ネオンカラーのアクセント、シャープなデザイン）

参考サイト: https://langgenius.co.jp/

レイアウト指定:

ヒーローエリア：左右2カラム配置（左：テキスト / 右：メインビジュアル・グラフィック）

特長・コース紹介：カードを3列のグリッド配置

2. デザイン・CSS設定

Google Fonts:

日本語: Noto Sans JP

英字・数字: Orbitron

カラー設定（CSS変数）:
css/style.css の :root で以下の変数を定義し、全体のスタイリングに使用してください。

:root {
  --font-family: 'Noto Sans JP', 'Orbitron', sans-serif;
  --primary-color: #00f0ff;    /* ネオンシアン */
  --secondary-color: #ff007f;  /* ネオンピンク */
  --bg-color: #0b0f19;         /* ダークネイビー */
  --card-bg-color: #161f30;    /* カード用背景 */
  --text-color: #e2e8f0;       /* ハイコントラストライトグレー */
}


3. コンテンツ・メイン文章

ヒーローキャッチコピー:
「未経験からプロになる！最先端のVibeコーディングと実践開発をマスターする。」

幅広く深いカリキュラム: HTML/CSSの基礎からAIを活用したモダン開発まで網羅。

爆速フィードバック: プロによるマンツーマンでのコードレビューと伴走サポート。

実践的ポートフォリオ構築: 現場で評価されるWebアプリケーションをゼロから制作。

4. JavaScript動的描画データ

js/script.js 内に配列データを保持し、DOM操作によって動的に要素を生成・描画してください。

① コースアイテムデータ（3つ）

フロントエンドマスターコース

AIパートナー・Vibeコーディング講座

フルスタックWeb開発実践ワークショップ

② FAQ（よくある質問・アコーディオンUI）

Q1: 完全なプログラミング未経験でも受講できますか？

A1: はい。基礎的なパソコン操作からAIツールの活用法まで、段階的に学べるステップアップ形式になっています。

Q2: 受講に必要な環境やPCスペックはありますか？

A2: VS Code等のテキストエディタと一般的なWebブラウザが動作する環境があれば問題ありません。

Q3: 質問やサポートの体制はどうなっていますか？

A3: 専用チャットツールで24時間いつでも質問を受け付けており、メンターが順次回答・フォローします。

5. 実装ルール・出力要件

ファイル構成: index.html, css/style.css, js/script.js の3ファイル構造とする。

デザイン性: サイバー・近未来感を感じさせるホバーエフェクト（ネオンの光彩やスムーズなトランジション）を取り入れること。

レスポンシブ対応: スマートフォン表示時はヒーローエリアを縦並び化し、3列グリッドを1列カード配置に切り替えること。

JS動的描画: コースカード一覧とFAQアコーディオンは、HTMLに直書きせずJavaScriptの配列データから動的生成すること。
